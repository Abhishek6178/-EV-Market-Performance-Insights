# EV Market Analysis Dashboard

## Project Overview
This project analyzes the Electric Vehicle (EV) market using Tableau.

## Objectives
- Analyze annual EV sales by manufacturer.
- Compare EV counts by battery technology.
- Analyze average driving range by vehicle category.
- Compare customer ratings across manufacturers.

## Tools Used
- Tableau Public
- EV Market Dataset

## Visualizations
1. Manufacturer-wise Annual EV Sales
2. EV Count by Battery Technology
3. Average Driving Range by Vehicle Category
4. Average Customer Rating by Manufacturer
